Initial ICP:

B2B software companies and SMB technology vendors that need to demonstrate compliance maturity to larger companies.

- sell B2B;
- handle customer data;

# 38. DECISION FRAMEWORK

When evaluating a marketing idea, ask:

1. Does it reach the ICP?
2. Does it communicate a real customer problem?
3. Does it differentiate Compliance OS?
4. Does it create trust?
5. Does it support conversion?
6. Can it be measured?
7. Is the claim defensible?
8. Does it reinforce the brand?
9. Does it create sustainable growth?
10. Is it worth the execution cost?

If not, challenge the idea.
